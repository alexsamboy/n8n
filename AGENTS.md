# n8n — Codex Project Instructions

## Graphify — Project Policy

Graphify is OPTIONAL and MANUAL.

Use it only when static architecture,
dependency, traceability or impact
analysis provides meaningful value.

Graphify does not have an approved
AST corpus for this repository.

AST corpus status: NOT APPROVED.

No Graphify snapshot is available.

Snapshot status: NOT AVAILABLE.

Graphify query authorization is
NOT GRANTED.

Query status: NOT AUTHORIZED.

Candidate source locations may include
reviewed, repository-owned JavaScript
and Python files.

Candidate locations are NOT an
approved allowlist.

Workflows JSON, runtime state,
execution records, credentials,
secrets, provider data, fixtures,
backups, logs, generated outputs
and production data are excluded.

MJML templates and operational scripts
require separate review.

Before any authorized operation,
verify exact worktree, project identity,
HEAD, approved corpus, exclusions,
manifest, snapshot provenance,
integrity hashes and privacy controls.

Each extraction, snapshot or query
requires specific authorization.

Never enable automatic indexing,
file-read hooks, watch mode, extraction,
updates or Graphify queries.

Do not transmit project data
to external services.

Graphify AST results are static
evidence, not proof of n8n runtime,
workflow execution or delivery.

Global Engineering OS instructions
and project security restrictions
remain authoritative.

Do not execute Graphify when any
required prerequisite is missing.

This policy does not authorize
changes to infrastructure or services.
